# Enterprise Observability & Monitoring Guide

Guide for launching and operating Grafana, Prometheus, Loki, Promtail, and ELK Stack.

---

## 📊 Endpoints & Access

- **Grafana**: [`http://localhost:3001`](http://localhost:3001) (`admin` / `adminpassword123`)
- **Prometheus**: [`http://localhost:9090`](http://localhost:9090)
- **Kibana (ELK)**: [`http://localhost:5601`](http://localhost:5601)

---

## 🚀 Execution Commands

```bash
# Start monitoring stack
npm run monitoring:up

# Stop monitoring stack
npm run monitoring:down
```
